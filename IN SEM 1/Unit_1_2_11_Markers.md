## Q1. 🔥 VERY IMPORTANT --- Explain the evolution of web technologies from Web 1.0 to modern AI-assisted web development. \[11 Marks\]

### Answer

### Introduction

Web technology has evolved from static information pages into highly
interactive, intelligent and personalized applications. The major stages
are commonly described as **Web 1.0, Web 2.0 and the emerging
intelligent/AI-assisted Web**.

### 1. Web 1.0 --- Read-only Web

Web 1.0 was the early stage of the World Wide Web.

**Characteristics:** - Mostly static HTML pages. - Information was
published by website owners. - Very limited user interaction. - Simple
hyperlinks and images were common. - Content was generally not
personalized. - Server-side processing and databases were limited
compared with modern systems.

**Example:** A static company information page containing About Us,
Services and Contact pages.

### 2. Web 2.0 --- Read-write and Interactive Web

Web 2.0 introduced extensive user participation and dynamic content.

**Characteristics:** - Dynamic web pages. - User-generated content. -
Social interaction and collaboration. - Client-side JavaScript became
important. - APIs and database-driven applications became common. -
Responsive and interactive interfaces became increasingly important.

**Examples:** social networking sites, online collaboration platforms
and modern web applications.

### 3. Modern AI-assisted Web

Modern web development increasingly combines web technologies with AI
and Generative AI.

**Characteristics:** - AI-assisted coding. - AI-generated UI layouts and
content. - Natural-language interaction. - Intelligent search and
recommendations. - AI-integrated web applications. - Personalized user
experiences. - Automated testing, debugging and documentation.

### Evolution flow

``` text
Web 1.0
Static / Read-only
      ↓
Web 2.0
Dynamic / Interactive / User-generated
      ↓
Modern Web
APIs + Rich Front-end + Cloud services
      ↓
AI-assisted Web
Generative AI + LLMs + Intelligent Applications
```

### Comparison

  -------------------------------------------------------------------------
  Feature           Web 1.0           Web 2.0           AI-assisted Web
  ----------------- ----------------- ----------------- -------------------
  Main model        Read              Read + Write      Read + Write +
                                                        Intelligent
                                                        interaction

  Content           Mostly static     Dynamic           Dynamic +
                                                        AI-generated

  User role         Consumer          Consumer +        Consumer +
                                      creator           creator +
                                                        natural-language
                                                        participant

  Interaction       Low               High              High + intelligent

  AI                Minimal/none      Limited           Central/enhancing
                                                        role

  Personalization   Limited           Moderate          Advanced
  -------------------------------------------------------------------------

### Conclusion

The evolution of the web shows a movement from static information
delivery toward interactive and intelligent applications. AI-assisted
development does not replace fundamental web technologies; rather, it
augments them to make development faster, more personalized and more
automated.

## Q2. 🔥 VERY IMPORTANT --- Explain front-end, back-end and full-stack development in detail. Compare their responsibilities, technologies and workflow. \[11 Marks\]

### Answer

### Introduction

A modern web application is generally divided into **front-end**,
**back-end**, and, when a developer works across both, **full-stack
development**.

### Front-end development

The front end is the part of a website/application that users directly
see and interact with.

**Major technologies:** - HTML5 --- structure - CSS3 --- presentation
and styling - JavaScript --- behavior and interaction - Bootstrap ---
responsive UI development

**Responsibilities:** - Designing user interfaces. - Handling user
interaction. - Creating responsive layouts. - Form creation and
validation. - Calling back-end APIs. - Improving accessibility and
usability.

### Back-end development

The back end runs on the server and handles application logic and data
processing.

**Responsibilities:** - Business/application logic. - Processing
requests. - Database interaction. - Authentication-related processing. -
API creation. - Server-side validation.

### Full-stack development

Full-stack development combines front-end and back-end development.

``` text
User
  ↓
Front End
HTML + CSS + JavaScript
  ↓ HTTP/API
Back End
Application Logic
  ↓
Database / Services
```

### Comparison

  --------------------------------------------------------------------------
  Aspect            Front End         Back End             Full Stack
  ----------------- ----------------- -------------------- -----------------
  Main focus        User interface    Server/application   Both
                                      logic                

  Runs mainly       Browser           Server               Browser + server

  Key concern       UX/UI             Logic/data           Complete
                                                           application

  Common syllabus   HTML, CSS, JS,    Server/API concepts  Combination
  technologies      Bootstrap                              

  User interaction  Direct            Indirect             Both
  --------------------------------------------------------------------------

### Typical workflow

1.  User interacts with the interface.
2.  Front end captures the action.
3.  A request is sent to the back end.
4.  Back end processes the request.
5.  Required data is obtained/updated.
6.  Response is returned.
7.  Front end updates the interface.

### Advantages of full-stack development

-   Better understanding of the complete application.
-   Easier coordination between front-end and back-end work.
-   Useful for prototypes and small teams.
-   Enables end-to-end feature development.

### Conclusion

Front-end, back-end and full-stack development represent different
levels of responsibility in web engineering. Understanding how these
layers communicate is essential for building complete web applications.

## Q3. 🔥 VERY IMPORTANT --- Explain Artificial Intelligence and Generative AI. Differentiate between traditional AI and Generative AI with suitable examples. \[11 Marks\]

### Answer

### Artificial Intelligence

Artificial Intelligence (AI) is the field of computing concerned with
creating systems capable of performing tasks that normally require
aspects of human intelligence, such as learning, reasoning, prediction
and decision-making.

### Generative AI

Generative AI is a class of AI systems capable of **generating new
content** from learned patterns and a user's input.

It can generate: - Text - Code - Images - Designs - Other forms of
content

### Traditional AI vs Generative AI

  -------------------------------------------------------------------------
  Aspect                  Traditional AI            Generative AI
  ----------------------- ------------------------- -----------------------
  Main purpose            Predict/classify/decide   Generate new content

  Typical output          Label, prediction,        Text, code, design,
                          decision                  etc.

  Example                 Spam classification       Generating an HTML page

  Interaction             Often task-specific       Frequently
                                                    natural-language based

  Development use         Analysis/automation       Creation + assistance
  -------------------------------------------------------------------------

### Generative AI in web development

Generative AI can assist with: - HTML/CSS/JavaScript code generation. -
UI design suggestions. - Content generation. - Debugging. -
Documentation. - Test-case generation. - Website prototyping. -
Prompt-based design exploration.

### Basic working

``` text
User Prompt
    ↓
Generative AI Model
    ↓
Learned Patterns + Context
    ↓
Generated Output
    ↓
Developer Review
    ↓
Integration into Web Application
```

### Advantages

-   Faster prototyping.
-   Reduces repetitive coding.
-   Helps generate alternatives.
-   Supports learning and explanation.
-   Can accelerate documentation and testing.

### Limitations

-   Generated output may be incorrect.
-   It can produce insecure or inefficient code.
-   It may misunderstand requirements.

useful as an assistant for design, coding, documentation and
prototyping.

## Q4. 🔥 VERY IMPORTANT --- Explain Large Language Models (LLMs), their major components/characteristics, working process and applications in web development. \[11 Marks\]

### Answer

### Introduction

A **Large Language Model (LLM)** is an AI model trained on very large
collections of text/code to understand and generate language-based
output.

### Major characteristics

-   Large number of learned parameters.
-   Ability to process natural language.
-   Context-sensitive generation.
-   Text generation and transformation.
-   Code understanding/generation.
-   Ability to follow natural-language instructions.

### Simplified working

``` text
Input / Prompt
     ↓
Tokenization
     ↓
Model processes contextual relationships
     ↓
Prediction of likely next token
     ↓
Repeated token generation
     ↓
Generated response
```

### Important concepts

**Tokens:**\
Text is divided into smaller units called tokens. The model processes
sequences of tokens rather than human concepts directly.

**Context:**\
The model uses surrounding input information to produce a contextually
relevant response.

**Training:**\
During training, the model learns statistical patterns and relationships
from large datasets.

**Inference:**\
Inference is the stage where the trained model receives an input and
produces an output.

### Applications in web development

1.  Generate HTML/CSS/JavaScript.
2.  Explain programming errors.
3.  Generate documentation.
4.  Suggest UI components.
5.  Create test cases.
6.  Convert natural-language requirements into implementation ideas.
7.  Assist with code refactoring.
8.  Generate website content.

### Limitations

-   Hallucinated or factually incorrect output.
-   Incorrect code.
-   Security vulnerabilities in generated code.
-   Context limitations.
-   Output needs validation.

### Conclusion

LLMs provide a natural-language interface for interacting with AI
systems. Their ability to understand instructions and generate code
makes them powerful assistants in modern web development.

## Q7. 🔥 VERY IMPORTANT --- Explain prompt engineering fundamentals for AI-assisted software development. Discuss the characteristics of an effective prompt with examples. \[11 Marks\]

### Answer

### Definition

Prompt engineering is the process of designing and refining instructions
given to an AI model to obtain useful, relevant and reliable output.

### Components of a good prompt

1.  **Role/context** --- specify the task or perspective.
2.  **Task** --- clearly state what must be done.
3.  **Input** --- provide necessary information.
4.  **Constraints** --- specify limitations.
5.  **Output format** --- define the expected structure.
6.  **Examples** --- provide examples when useful.

### Weak vs strong prompt

**Weak:**

``` text
Make a website.
```

**Better:**

``` text
Create a responsive college event webpage using HTML5, CSS3 and
Bootstrap. Include a navigation bar, event cards, registration form,
mobile-friendly layout and accessible labels. Return clean,
well-commented code.
```

### Prompt refinement process

``` text
Initial Prompt
      ↓
Generate Output
      ↓
Evaluate Output
      ↓
Identify Missing Requirements
      ↓
Refine Prompt
      ↓
Better Output
```

### Important techniques

-   Be specific.
-   Break complex tasks into steps.
-   Specify the technology.
-   Specify constraints.
-   Request structured output.
-   Provide relevant context.
-   Ask for explanations when learning.

### Advantages

-   More relevant output.
-   Reduced ambiguity.
-   Better consistency.
-   Faster development.
-   Improved communication with AI systems.

### Limitations

-   A good prompt cannot guarantee correct output.
-   Model limitations still exist.
-   Ambiguous requirements can produce wrong solutions.

### Conclusion

Prompt engineering is an important skill in AI-assisted development
because the quality of instructions strongly influences the usefulness
of generated output.

## Q8. 🔥 VERY IMPORTANT --- Discuss ethical and responsible use of AI in software development. \[11 Marks\]

### Answer

### Introduction

AI can significantly improve software development, but irresponsible use
can introduce technical, ethical and security risks. Responsible AI
means using AI in a manner that is safe, transparent, fair and
accountable.

### Major ethical considerations

**1. Privacy**\
Developers should avoid unnecessarily exposing personal, confidential or
sensitive information to AI systems.

**2. Security**\
AI-generated code must be checked for vulnerabilities.

**3. Accuracy**\
AI output can be incorrect. Important decisions require verification.

**4. Bias and fairness**\
Training data and generated output may contain biases.

**5. Intellectual property**\
Developers should consider licensing and ownership issues related to
generated content and code.

**6. Transparency**\
Appropriate disclosure and documentation may be required when AI
substantially contributes to work.

**7. Human accountability**\
The developer/team remains responsible for the final software.

### Responsible workflow

``` text
AI Suggestion
    ↓
Human Review
    ↓
Security / Accuracy Check
    ↓
Testing
    ↓
Ethical / Privacy Review
    ↓
Final Use
```

### Best practices

-   Do not submit confidential data unnecessarily.
-   Verify generated facts and code.
-   Test generated implementations.
-   Perform security checks.
-   Avoid blind dependence.
-   Keep humans responsible for final decisions.
-   Follow organizational and legal requirements.

### Advantages of responsible use

-   Safer software.
-   Greater user trust.
-   Reduced errors.
-   Better accountability.
-   More sustainable AI adoption.

### Conclusion

AI is most effective when used as a productivity and reasoning aid under
human supervision. Responsible use combines the speed of AI with human
judgment, verification and accountability.

### Definition

### Principles

1.  Flexible layouts.
2.  Flexible images/media.
3.  Media queries.
4.  Mobile-friendly navigation.
5.  Appropriate typography and spacing.

``` text
Desktop / Tablet / Mobile Requirements
              ↓
Flexible Layout
              ↓
Flexible Images
              ↓
Media Queries
              ↓
Testing at Different Widths
              ↓
Responsive Website
```

### Example

``` css
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 768px) {
    .grid {
        grid-template-columns: 1fr;
    }

```

The layout changes from three columns to one column on smaller screens.

### Advantages

-   Better mobile experience.
-   One website can support multiple screen sizes.
-   Improved usability.
-   Better maintainability than maintaining separate versions.

### Limitations

-   Requires careful testing.
-   Complex layouts may need additional CSS.
-   Poorly designed responsive rules can create usability problems.

### Conclusion

Responsive design is essential for modern web interfaces because users
access websites through devices with different screen dimensions.

  Consistency            Built-in baseline         Must be designed

### Conclusion

Bootstrap is useful when speed and reusable responsive components are
important, while custom CSS is preferable when highly tailored styling
and complete control are priorities.

## Q39. 🔥 VERY IMPORTANT --- Compare traditional web development with AI-assisted web development. Discuss differences across planning, design, coding, testing, documentation and maintenance. \[11 Marks\]

### Answer

### Introduction

Traditional development relies primarily on manual human implementation,
whereas AI-assisted development adds AI tools to support multiple
development activities.

### Comparison

  ---------------------------------------------------------------------------
  Phase                   Traditional             AI-assisted
  ----------------------- ----------------------- ---------------------------
  Planning                Manual analysis         AI can summarize/break down

  Design                  Manual ideation         AI can suggest alternatives

  Coding                  Mostly manual           AI can generate/complete
                                                  code

  Debugging               Manual investigation    AI can explain errors

  Testing                 Manually designed       AI can suggest test cases

  Documentation           Manual writing          AI can draft documentation

  Maintenance             Manual code analysis    AI can assist with
                                                  understanding/refactoring
  ---------------------------------------------------------------------------

### Important difference

AI-assisted does not mean AI-controlled. Human developers still need to
verify: - Correctness. - Security. - Accessibility. - Performance. -
Requirement compliance.

### Advantages

-   Faster prototyping.
-   Productivity improvement.
-   Reduced repetitive work.

### Risks

-   Incorrect output.
-   Security issues.
-   Overdependence.
-   Ethical concerns.

### Conclusion

AI-assisted development changes the workflow rather than eliminating
software engineering. The developer's role increasingly includes
directing, evaluating and validating AI-generated work.
