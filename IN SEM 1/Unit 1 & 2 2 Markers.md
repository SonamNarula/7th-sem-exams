# UNIT 1 — INTRODUCTION TO WEB DEVELOPMENT AND GENERATIVE AI

## 1. Evolution of Web Technologies

### 🟢 Basic

**What is meant by Web 1.0? [2 Marks]** 🔥
Web 1.0 refers to the earliest phase of the World Wide Web (mid-1990s) consisting of static, read-only web pages with no user interaction. It was purely informational, with content authored by a small number of publishers.

**What is Web 2.0? [2 Marks]** 🔥
Web 2.0 is the second generation of the web characterized by dynamic, interactive websites, user-generated content, and social media platforms. It enabled two-way communication between users and websites.

**What is Web 3.0? [2 Marks]** ⭐
Web 3.0 is the emerging phase of the web based on decentralization, semantic understanding, and AI-driven personalization, often associated with blockchain and machine-readable data.

**Define static website. [2 Marks]** ○
A static website displays fixed content that is the same for every visitor and does not change unless manually edited by a developer.

**Define dynamic website. [2 Marks]** ○
A dynamic website generates content in real time based on user interaction, database queries, or server-side processing.

### 🟡 Conceptual

**Differentiate between Web 1.0 and Web 2.0. [2 Marks]** 🔥

| Web 1.0 | Web 2.0 |
|---|---|
| Read-only, static | Read-write, interactive |
| One-way communication | Two-way communication |
| No user content | User-generated content |

**How does Web 3.0 differ from Web 2.0? [2 Marks]** ⭐
Web 2.0 is centralized and platform-controlled, while Web 3.0 emphasizes decentralization, user data ownership, and AI/semantic-based content understanding.

**Why is the evolution of web technologies important for modern development? [2 Marks]** ○
It shows the shift from static content to interactive, intelligent, and personalized systems, guiding developers toward using current best practices and tools.

### 🔴 Tricky / Examiner-Twist

**Give one real-world example each for Web 1.0, 2.0 and 3.0 platforms. [2 Marks]** ⭐
Web 1.0: early static company brochure sites. Web 2.0: Facebook, YouTube (user-generated content). Web 3.0: decentralized apps (dApps) and blockchain-based platforms.

## 2. Front-end Development

### 🟢 Basic

**What is front-end development? [2 Marks]** 🔥
Front-end development refers to building the part of a website or application that users directly interact with, including layout, design, and interactivity.

**List any three front-end technologies. [2 Marks]** 🔥
HTML, CSS, and JavaScript.

**What is a front-end framework? [2 Marks]** ⭐
A front-end framework is a pre-written collection of code (like React or Angular) that provides structure and reusable components to speed up building user interfaces.

**Name any two front-end frameworks/libraries. [2 Marks]** ⭐
React.js and Angular (also: Vue.js).

### 🟡 Conceptual

**What is the primary purpose of front-end development? [2 Marks]** 🔥
Its purpose is to create the visual, interactive, and user-facing part of an application, ensuring usability and a good user experience.

**What is the role of JavaScript in front-end development? [2 Marks]** ⭐
JavaScript adds interactivity and dynamic behavior to web pages, such as responding to user actions, updating content, and validating forms.

### 🔴 Tricky / Examiner-Twist

**Why is front-end development also called "client-side development"? [2 Marks]** ○
Because the code runs in the user's browser (the client) rather than on the server.

## 3. Back-end Development

### 🟢 Basic

**What is back-end development? [2 Marks]** 🔥
Back-end development refers to server-side development that manages databases, application logic, and server operations, which are not directly visible to users.

**List any three back-end technologies/languages. [2 Marks]** 🔥
Node.js, Python (Django/Flask), and PHP (also: Java, Ruby on Rails).

**What is a server? [2 Marks]** ⭐
A server is a computer or program that provides data, resources, or services to client applications over a network.

**What is a database in the context of back-end development? [2 Marks]** ⭐
A database is an organized collection of data stored and managed on the server side, used to store, retrieve, and manipulate application data.

### 🟡 Conceptual

**What is the main function of back-end development? [2 Marks]** 🔥
It handles data storage, business logic, authentication, and communication between the server and the front-end/database.

**How does back-end development differ from front-end development? [2 Marks]** 🔥

| Front-end | Back-end |
|---|---|
| Client-side, visible to user | Server-side, hidden from user |
| Handles UI/UX | Handles logic, database, server |
| HTML, CSS, JS | Node.js, PHP, Python, etc. |

### 🔴 Tricky / Examiner-Twist

**Why is back-end development referred to as "server-side development"? [2 Marks]** ○
Because its code executes on the server rather than in the user's browser, processing requests before sending results to the client.

## 4. Full Stack Development

### 🟢 Basic

**What is full stack development? [2 Marks]** 🔥
Full stack development refers to the practice of working on both front-end (client-side) and back-end (server-side) portions of an application.

**Who is a full stack developer? [2 Marks]** 🔥
A full stack developer is a professional skilled in both front-end and back-end technologies, capable of building complete web applications independently.

**What does the term "stack" refer to in full stack development? [2 Marks]** ⭐
"Stack" refers to the combination of technologies (front-end, back-end, database) used together to build an application, e.g., the MERN stack.

**Give an example of a full stack (technology combination). [2 Marks]** ⭐
MERN stack: MongoDB, Express.js, React.js, Node.js.

### 🟡 Conceptual

**What are the advantages of full stack development? [2 Marks]** ⭐
It allows a single developer to handle entire projects, reduces communication gaps between teams, and offers flexibility and faster development.

### 🔴 Tricky / Examiner-Twist

**Why might a company prefer hiring full stack developers over separate front-end and back-end specialists? [2 Marks]** ○
Full stack developers reduce costs, improve coordination, and can independently manage smaller projects end-to-end.

## 5. Introduction to Artificial Intelligence

### 🟢 Basic

**Define Artificial Intelligence (AI). [2 Marks]** 🔥
Artificial Intelligence is the branch of computer science that enables machines to simulate human intelligence, such as learning, reasoning, and problem-solving.

**What are the main types of AI based on capability? [2 Marks]** ⭐
Narrow AI (Weak AI), General AI, and Super AI.

**What is Machine Learning (ML)? [2 Marks]** 🔥
Machine Learning is a subset of AI that enables systems to learn patterns from data and improve performance without being explicitly programmed.

**What is Deep Learning? [2 Marks]** ⭐
Deep Learning is a subset of Machine Learning that uses multi-layered artificial neural networks to model complex patterns in large datasets.

### 🟡 Conceptual

**How does AI differ from traditional programming? [2 Marks]** 🔥
Traditional programming follows fixed rules written by a programmer, while AI systems learn patterns from data to make decisions or predictions.

**What is the relationship between AI, ML, and Deep Learning? [2 Marks]** ⭐
AI is the broadest field; Machine Learning is a subset of AI; Deep Learning is a further subset of Machine Learning using neural networks.

**Give two real-world applications of AI. [2 Marks]** ○
Voice assistants (Siri, Alexa) and recommendation systems (Netflix, Amazon).

## 7. Large Language Models (LLMs)

### 🟢 Basic

**What is a Large Language Model (LLM)? [2 Marks]** 🔥
An LLM is a type of AI model trained on massive amounts of text data using deep learning (transformer architecture) to understand and generate human-like language.

**Give two examples of LLMs. [2 Marks]** 🔥
GPT (by OpenAI) and Gemini (by Google) (also: Claude, LLaMA).

**What is a "token" in the context of LLMs? [2 Marks]** ⭐
A token is a basic unit of text (word or sub-word) that an LLM processes as input or output during language generation.

**What does "transformer architecture" mean? [2 Marks]** ⭐
The transformer is a neural network architecture that uses a mechanism called "attention" to process input sequences in parallel, forming the foundation of modern LLMs.

### 🟡 Conceptual

**What is the primary use of LLMs in software development? [2 Marks]** 🔥
LLMs assist in code generation, debugging, documentation writing, and answering technical queries through natural language prompts.

**How do LLMs generate human-like text? [2 Marks]** ⭐
LLMs predict the most probable next word/token in a sequence based on patterns learned from massive training datasets.

### 🔴 Tricky / Examiner-Twist

**Why can LLMs sometimes produce incorrect or fabricated information ("hallucination")? [2 Marks]** ⭐
Because LLMs generate responses based on statistical patterns rather than verified facts, they may produce plausible-sounding but inaccurate content.

## 10. Prompt Engineering Fundamentals

### 🟢 Basic

**What is Prompt Engineering? [2 Marks]** 🔥
Prompt Engineering is the practice of designing and refining input queries (prompts) to get accurate, relevant, and useful responses from AI models.

**What is a "prompt"? [2 Marks]** 🔥
A prompt is the input text or instruction given to an AI model to generate a desired output.

**What is zero-shot prompting? [2 Marks]** ⭐
Zero-shot prompting means asking an AI model to perform a task without giving it any prior examples.

**What is few-shot prompting? [2 Marks]** ⭐
Few-shot prompting means providing the AI model with a few examples within the prompt to guide it toward the desired output format/behavior.

### 🟡 Conceptual

**What are the key elements of a good prompt? [2 Marks]** 🔥
Clarity, context, specific instructions, and (where needed) examples or desired output format.

**Why is prompt engineering important in AI-assisted development? [2 Marks]** 🔥
Well-crafted prompts lead to more accurate and useful AI outputs, reducing the need for repeated corrections and improving productivity.

### 🔴 Tricky / Examiner-Twist

**How does chain-of-thought prompting improve AI responses? [2 Marks]** ⭐
It encourages the AI model to reason step-by-step before giving a final answer, improving accuracy on complex or multi-step problems.

# UNIT 2 — AI-ASSISTED FRONT-END DEVELOPMENT

## 1. HTML5

### 🟢 Basic

**What is HTML5? [2 Marks]** 🔥
HTML5 is the fifth and latest major version of Hypertext Markup Language used to structure and present content on the web, with added support for multimedia and semantic elements.

**What does HTML stand for? [2 Marks]** 🔥
Hypertext Markup Language.

**What are semantic elements in HTML5? [2 Marks]** 🔥
Semantic elements are HTML tags that clearly describe their meaning/content, such as `<header>`, `<footer>`, `<article>`, and `<nav>`.

**Name any three new semantic tags introduced in HTML5. [2 Marks]** ⭐
`<header>`, `<footer>`, and `<section>` (also: `<article>`, `<nav>`, `<aside>`).

**What is the use of the `<canvas>` tag in HTML5? [2 Marks]** ⭐
The `<canvas>` tag is used to draw graphics, animations, and images dynamically via JavaScript.

**What is the purpose of the `<video>` and `<audio>` tags? [2 Marks]** ⭐
They allow embedding video and audio content directly in a webpage without requiring external plugins.

### 🟡 Conceptual

**How does HTML5 differ from HTML4? [2 Marks]** 🔥

| HTML4 | HTML5 |
|---|---|
| No semantic tags | Semantic tags available |
| Needs plugins for audio/video | Native audio/video support |
| No canvas/SVG support | Supports canvas and SVG |

**What is the purpose of the `<!DOCTYPE html>` declaration? [2 Marks]** ⭐
It tells the browser which version of HTML is being used, ensuring the page renders in standards mode.

**What are HTML5 form input types? Give two examples. [2 Marks]** ⭐
New input types like `email` and `date` (also: `number`, `url`, `tel`, `range`) allow better validation and input control.

### 🔴 Tricky / Examiner-Twist

**Why is semantic HTML important for SEO and accessibility? [2 Marks]** ⭐
Semantic tags help search engines and screen readers understand page structure and content meaning, improving SEO ranking and accessibility for users with disabilities.

## 2. CSS3

### 🟢 Basic

**What is CSS3? [2 Marks]** 🔥
CSS3 is the latest version of Cascading Style Sheets used to style and format the layout of HTML web pages, introducing features like animations, gradients, and flexbox.

**What does CSS stand for? [2 Marks]** 🔥
Cascading Style Sheets.

**What is a CSS selector? [2 Marks]** ⭐
A CSS selector is a pattern used to select and style HTML elements, such as class selectors (`.class`) or ID selectors (`#id`).

**What is the CSS Box Model? [2 Marks]** 🔥
The CSS Box Model describes an element's layout as consisting of content, padding, border, and margin.

**What are CSS pseudo-classes? Give an example. [2 Marks]** ⭐
Pseudo-classes define a special state of an element, e.g., `:hover` applies styles when the mouse hovers over an element.

### 🟡 Conceptual

**What is Flexbox in CSS3? [2 Marks]** 🔥
Flexbox is a CSS layout model that allows elements within a container to be aligned and distributed efficiently, even with dynamic sizes.

**What is CSS Grid? [2 Marks]** 🔥
CSS Grid is a two-dimensional layout system that allows arranging elements into rows and columns for complex layouts.

**Differentiate between Flexbox and Grid. [2 Marks]** ⭐

| Flexbox | Grid |
|---|---|
| One-dimensional layout | Two-dimensional layout |
| Best for rows OR columns | Best for rows AND columns |

**What is the difference between inline, internal, and external CSS? [2 Marks]** 🔥

| Type | Description |
|---|---|
| Inline | Style attribute within HTML tag |
| Internal | `<style>` tag inside `<head>` |
| External | Separate .css file linked via `<link>` |

### 🔴 Tricky / Examiner-Twist

**What is the CSS "cascade" and how does specificity affect it? [2 Marks]** ⭐
The cascade determines which CSS rule applies when multiple rules target the same element, based on specificity, source order, and importance (`!important`).

## 3. Responsive Web Design

### 🟢 Basic

**What is Responsive Web Design (RWD)? [2 Marks]** 🔥
Responsive Web Design is an approach that makes web pages render well on all devices and screen sizes by adapting layout dynamically.

**What is a media query in CSS? [2 Marks]** 🔥
A media query is a CSS technique used to apply styles conditionally based on device characteristics like screen width or orientation.

**What is the viewport meta tag used for? [2 Marks]** ⭐
It controls the page's dimensions and scaling on mobile browsers, ensuring proper responsive rendering.

### 🟡 Conceptual

**What is the difference between adaptive and responsive design? [2 Marks]** ⭐

| Adaptive Design | Responsive Design |
|---|---|
| Uses fixed layouts for set breakpoints | Uses fluid layouts that adjust continuously |

**What are breakpoints in responsive design? [2 Marks]** ⭐
Breakpoints are specific screen-width values at which the layout changes to adapt to different devices.

**Why is a "mobile-first" approach used in responsive design? [2 Marks]** ⭐
It ensures the design works well on smaller screens first, then progressively enhances for larger screens, improving performance and usability.

### 🔴 Tricky / Examiner-Twist

**Why is responsive web design important for modern websites? [2 Marks]** 🔥
It ensures usability and consistent user experience across devices (mobile, tablet, desktop), which is essential given the diversity of screen sizes today.

## 5. JavaScript Fundamentals

### 🟢 Basic

**What is JavaScript? [2 Marks]** 🔥
JavaScript is a lightweight, interpreted programming language used to add interactivity and dynamic behavior to web pages.

**What are the data types in JavaScript? [2 Marks]** 🔥
Primitive types include String, Number, Boolean, Undefined, Null, and Symbol; the non-primitive type is Object.

**What is a variable in JavaScript? [2 Marks]** ○
A variable is a named container used to store data values, declared using `var`, `let`, or `const`.

**What is the difference between `var`, `let`, and `const`? [2 Marks]** 🔥

| var | let | const |
|---|---|---|
| Function-scoped | Block-scoped | Block-scoped |
| Can be redeclared | Cannot be redeclared | Cannot be redeclared |
| Reassignable | Reassignable | Not reassignable |

**What is a function in JavaScript? [2 Marks]** ○
A function is a reusable block of code designed to perform a specific task, executed when called/invoked.

### 🟡 Conceptual

**What is an event in JavaScript? [2 Marks]** ⭐
An event is an action or occurrence (like a click or keypress) that JavaScript can detect and respond to.

**What is the difference between `==` and `===` in JavaScript? [2 Marks]** 🔥
`==` compares values with type coercion, while `===` compares both value and data type without coercion (strict equality).

**What is an arrow function? [2 Marks]** ⭐
An arrow function is a shorter syntax for writing JavaScript functions, introduced in ES6, e.g., `const add = (a, b) => a + b;`.

### 🔴 Tricky / Examiner-Twist

**Why is JavaScript called a "client-side scripting language"? [2 Marks]** ○
Because it primarily runs in the user's web browser to control page behavior, rather than on the server.

## 10. AI-generated Responsive Layouts
